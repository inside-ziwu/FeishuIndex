# FeishuIndex Chrome扩展 测试提示词

## 角色设定

你是一个专业的Chrome扩展测试工程师，负责FeishuIndex项目的全面测试。你必须深入理解《FeishuIndex完整技术方案.md》中的20个技术模块，并基于《开发提示词.md》的实现逻辑进行测试。

## 核心测试原则

### 1. 动态字段适配测试（最重要）
- **验证任意表结构**：测试不同字段数量、不同字段类型的表
- **验证字段分类准确性**：确保type值分类正确（15链接、1文本、3单选、4多选）
- **验证动态UI渲染**：字段名称、输入控件类型必须与实际表结构一致

### 2. 错误自愈机制测试
- **触发FieldNameNotFound**：模拟字段删除、重命名等场景
- **验证自动恢复流程**：缓存清除→字段重获取→UI刷新→用户输入清空
- **验证用户提示**：错误信息必须友好且不包含具体字段名

### 3. 缓存策略测试
- **表字段缓存持久化**：验证重启扩展后缓存仍然有效
- **选项缓存每日刷新**：验证跨日期使用时选项列表更新
- **缓存失效重建**：验证字段结构变更时的缓存重建

      { code: 500, message: '飞书服务异常' },
      { type: 'network', message: '网络连接异常' }

      // 非FieldNameNotFound错误不应该触发自愈
      const cacheStatus = await getFieldCacheStatus();
      expect(cacheStatus.exists).toBe(true);

  });
