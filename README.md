# FeishuIndex Chrome扩展

> 将任意网页URL一键保存到飞书多维表格的智能工具

## 🚀 项目简介

FeishuIndex是一个基于Manifest V3的Chrome扩展，核心功能是将浏览的任意网页URL（包括微信公众号、飞书文档、小红书等）快速保存到飞书多维表格中进行归档和检索。

### 核心特点

- **🔄 动态字段适配**：支持任意表结构，基于字段类型自动识别和渲染
- **⚙️ 简化配置**：仅需3个配置项，1分钟完成设置
- **🛡️ 错误自愈**：字段结构变更时自动刷新，无需手动干预
- **🔍 智能查重**：URL完全相等匹配，避免重复保存
- **📝 多字段支持**：链接、文本、单选、多选4种字段类型

## 📋 功能特性

### 支持的字段类型

| 字段类型 | 飞书类型 | 说明 | 必需性 |
|---------|---------|------|--------|
| 🔗 链接字段 | 超链接 | 自动填入当前网页URL | ✅ 必需 |
| 📝 文本字段 | 文本/多行文本 | 用户手动输入内容 | ⚪ 可选 |
| 🎯 单选字段 | 单选 | 下拉选择或输入新选项 | ⚪ 可选 |
| ☑️ 多选字段 | 多选 | 多选或批量输入标签 | ⚪ 可选 |

### 核心功能

- ✅ **一键保存**：点击扩展图标，填写信息，快速保存
- ✅ **URL查重**：自动检测重复URL，支持覆盖更新
- ✅ **动态表单**：根据表结构自动生成输入界面
- ✅ **错误自愈**：表结构变更时自动恢复
- ✅ **选项管理**：支持创建新的选项，立即可用
- ✅ **缓存优化**：智能缓存策略，减少API调用

## 📦 安装和使用

### 开发环境安装

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd Feishuindex
   ```

2. **准备图标文件**
   - 在 `icons/` 目录下放置 `icon16.png`, `icon48.png`, `icon128.png`
   - 参考 `icons/README.md` 的设计建议

3. **加载扩展**
   - 打开 Chrome 浏览器
   - 访问 `chrome://extensions/`
   - 开启"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择项目根目录

### 使用配置

1. **配置飞书应用**
   - 访问 [飞书开放平台](https://open.feishu.cn/app)
   - 创建应用或选择已有应用
   - 获取 App ID 和 App Secret
   - 在权限管理中添加"多维表格"权限

2. **配置扩展**
   - 点击扩展图标，选择"选项"
   - 填写 App ID、App Secret 和表格URL
   - 点击"测试连接"验证配置

3. **准备表格**
   - 确保表格中有链接类型的字段（必需）
   - 可以添加文本、单选、多选字段（可选）
   - 将应用添加为表格协作者

### 日常使用

1. 在任意网页点击扩展图标
2. 查看自动填入的URL
3. 填写其他字段信息
4. 点击"保存记录"
5. 如有重复，选择是否覆盖更新

## 🔧 开发指南

### 核心模块

1. **field-mapper.js** - 动态字段适配核心
   - 字段类型分类和映射
   - 表单数据构建
   - 验证逻辑

2. **feishu-api.js** - API封装
   - Token管理
   - API调用封装
   - 错误处理

3. **storage.js** - 存储管理
   - 配置存储
   - 缓存策略
   - 状态管理

4. **background.js** - Service Worker
   - 核心业务逻辑
   - 错误自愈机制
   - 消息路由

### 开发原则

- **动态适配**：绝不使用固定字段名
- **错误自愈**：自动处理表结构变更
- **性能优先**：智能缓存和频率控制
- **用户友好**：清晰的错误提示和状态反馈
